NICE reference case for health effects (PMG36 as amended by PMG51, 2026)

https://healtheconomics.wiki/ontologies/oheo/OHEO_0000390
Curation status ready for releaseexternal

A reference case profile setting the methods NICE requires for measuring, valuing and discounting health effects, as set by its 2022 manual (PMG36) and amended by the interim methods statement of 27 August 2026 (PMG51), which adopts the EQ-5D-5L value set.

Also known as NICE PMG51 reference case; NICE reference case
Type reference case profile
alternative label NICE reference case for health effects (2026)
date issued 2026-08-27
definition source NICE 2026 (PMG51, Interim methods statement: implementing the EQ-5D-5L value set, 27 August 2026); NICE 2022 (PMG36)
editor note Checked against the full text of PMG51 (read on 18 October 2026). PMG51 makes the EQ-5D-5L descriptive system with the UK EQ-5D-5L value set (Rowen et al. 2026) NICE's preferred approach in adults, and that value set should derive all adult utility values in reference-case analyses (1.6, 1.7, Appendix A 4.3.6). It applies to TA, HST and HealthTech evaluations and to guidelines (PMG20).
EQ-5D-3L value set utilities must not be used in sensitivity or scenario analyses (1.13). Non-UK EQ-5D-5L value sets are never preferred over mapping to the UK value set (FAQ 17). NICE recommends no specific measure for children and young people, so these value set rules do not apply to EQ-5D-Y data (1.7, FAQ 19).
PMG51 applies prospectively, to topics whose invitation to participate (TA, HST), launch (HealthTech) or selection (guidelines) came after 27 August 2026. Topics started before keep the PMG36 approach (1.17, 1.18, FAQ 16). The rules therefore key on the analysis's topic start date (OHEO_2000035).
The 5L value set is also used for general population utilities and the QALY shortfall behind the severity modifier, whose cut-offs are unchanged from PMG36 table 6.1 (1.12, FAQ 21). The discount rate of 3.5% and the use of QALYs are those of PMG36. Costs and NICE's cost-effectiveness threshold are RHEO matters and are not checked here.
When only EQ-5D-3L data exist, they are mapped to EQ-5D-5L utilities with the NICE DSU response mapping model on the EEPRU dataset (Hernández Alava, Pudney and Wailoo 2023), with the Rowen 2026 value set applied as a separate step. Using mapped 3L data, 5L literature values or non-EQ-5D measures mapped to the 5L value set is a departure from the reference case (1.10, 1.11, Appendix A 4.3.8 to 4.3.10).

Also known as NICE PMG36 reference case
Type reference case profile
alternative label NICE reference case for health effects (2022)
date issued 2022-01-31
definition source NICE 2022 (PMG36)
editor note Superseded for new topics by PMG51 (27 August 2026). Topics started before that date keep these rules, so the profile stays valid for them (PMG51 1.17, 1.18).
Under PMG36, utilities came from the EQ-5D-3L UK value set (Dolan 1997); EQ-5D-5L responses were mapped to it with the NICE DSU mapping (Hernández Alava et al. 2017) using the EEPRU dataset (Hernández Alava et al. 2023), and the EQ-5D-5L value set for England (Devlin et al. 2018) was not recommended (old PMG36 4.3.16, as quoted in PMG51). The value set rules do not apply to EQ-5D-Y data.
