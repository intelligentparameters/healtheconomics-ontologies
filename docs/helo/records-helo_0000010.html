prerequisite from HEO assumes

https://healtheconomics.wiki/ontologies/helo/HELO_4000033
Curation status pending final vettingexternal

A prerequisite derivation rule by which a HEO assumes relationship from a method or model to an assumption gives the proposal that the assumption is understood no later than the method or model, so that the two may be taught in one step.

Type prerequisite derivation rule
contributor Michelle Ashleyexternal
definition source HELO 0.2.0 design (best practice), Michelle Ashley with Claude, 19 October 2026; HEO 2.0.0
differentFrom prerequisite from HEO used to calculate
editor note HEO marks assumes for learning. Assumptions are usually taught with their method, so a pair in one step agrees with the pathway and only an assumption taught later conflicts (curator decision, 19 October 2026, after review B S2).

prerequisite from HEO used to calculate

https://healtheconomics.wiki/ontologies/helo/HELO_4000034
Curation status pending final vettingexternal

A prerequisite derivation rule by which a HEO used to calculate relationship from an input to a result gives the weaker proposal that the input is understood before the result, only where the input is part of what the result means, read as the HEO definition of the result naming the input.

Type prerequisite derivation rule
contributor Michelle Ashleyexternal
definition source HELO 0.2.0 design (best practice), Michelle Ashley with Claude, 19 October 2026; HEO 2.0.0
editor note HEO marks used to calculate for formal inference and navigation, not for learning, so HELO keeps these proposals as a separate weaker tier (curator decision, 19 October 2026). An input that is only one way of computing the result, such as cumulative hazard for a transition probability, gives no proposal (review B S1).
