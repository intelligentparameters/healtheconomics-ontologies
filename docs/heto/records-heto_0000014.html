Conduct sensitivity analysis

https://healtheconomics.wiki/ontologies/heto/HETO_4000013

A task specification for testing whether the results and the decision of an economic evaluation change when uncertain inputs, assumptions or structural choices are varied.

Type uncertainty analysis task specification
contributor Michelle Ashleyexternal
definition source Briggs, Claxton and Sculpher 2006
expected output description Sensitivity analysis results.
has action specification Identify the uncertain parameters, assumptions and structural choices
Vary them and record the effect on the results and on the decision
has input type uncertainty specification, economic model version
has objective specification Show how far the results and the decision depend on uncertain inputs and assumptions
has output type model result
has practitioner role economic modeller role
has process type model run
has subtask specification Run a deterministic sensitivity analysis, Run a probabilistic sensitivity analysis, Run scenario analyses
inputs description The economic model version, its base-case results and descriptions of the uncertainty in its inputs.
normally precedes Report an economic evaluation
term editor Michelle Ashley (drafted with Claude)

Run a deterministic sensitivity analysis

https://healtheconomics.wiki/ontologies/heto/HETO_4000014

A task specification for re-running an economic model with chosen inputs set to alternative fixed values, one or a few at a time, to see which inputs drive the results.

Type uncertainty analysis task specification
alternative label Run a DSA
contributor Michelle Ashleyexternal
definition source Briggs, Claxton and Sculpher 2006
expected output description Deterministic sensitivity analysis results, such as a table or a tornado diagram.
has action specification Choose the inputs to vary and their alternative values
Re-run the model for each set of values and tabulate or plot the results
has input type uncertainty specification, economic model version
has objective specification Identify the inputs whose plausible values most change the results or the decision
has output type model result
has practitioner role economic modeller role
has process type model run
inputs description The economic model version and plausible ranges for its inputs.
term editor Michelle Ashley (drafted with Claude)

Run a probabilistic sensitivity analysis

https://healtheconomics.wiki/ontologies/heto/HETO_4000015

A task specification for running an economic model many times with all uncertain inputs drawn jointly from probability distributions, to estimate expected costs and outcomes and the probability that each option is cost-effective across a range of threshold values.

Type uncertainty analysis task specification
alternative label Run a PSA
contributor Michelle Ashleyexternal
definition source Briggs, Claxton and Sculpher 2006
expected output description The set of simulated results and their summaries.
has action specification Assign a probability distribution to each uncertain parameter
Run the model repeatedly with values sampled from those distributions
Summarise the simulated results, for example on a cost-effectiveness plane, an acceptability curve and an acceptability frontier
has input type uncertainty specification, economic model version, joint uncertainty specification, correlation specification
has objective specification Estimate expected results and the probability that each option is cost-effective across a range of threshold values, given joint parameter uncertainty
has output type model result, draw set
has practitioner role economic modeller role
has process type model run
inputs description The economic model version and the evidence on the uncertainty of each parameter.
term editor Michelle Ashley (drafted with Claude)

Run scenario analyses

https://healtheconomics.wiki/ontologies/heto/HETO_4000019

A task specification for re-running an economic model under alternative assumptions or structural choices, such as another survival extrapolation or another source of evidence, to see whether the results or the decision change.

Type uncertainty analysis task specification
contributor Michelle Ashleyexternal
definition source Briggs, Claxton and Sculpher 2006
expected output description Scenario analysis results.
has action specification Choose the alternative assumptions and structural choices to test
Re-run the model under each scenario and compare the results with the base case
has input type modelling assumption, economic model version, parameter assignment
has objective specification Show whether the decision changes under plausible alternative assumptions and structures
has output type model result
has practitioner role economic modeller role
has process type model run
inputs description The economic model version and the alternative assumptions or structures to test.
term editor Michelle Ashley (drafted with Claude)
