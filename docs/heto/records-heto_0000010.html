Define the decision problem

https://healtheconomics.wiki/ontologies/heto/HETO_4000002

A task specification for stating the decision an economic evaluation is to inform, including the population, the options compared, the outcomes, the perspective and the time horizon, before any analysis begins.

Type decision problem framing task specification
contributor Michelle Ashleyexternal
definition source Drummond et al. 2015
expected output description A decision problem specification.
has action specification Identify the population, the intervention and the comparators
Specify the costs and outcomes to be counted
Align the evaluation methods with the methods guidance of the decision maker or assessment body
Record the decision problem for the evaluation team and the decision maker
has input type documentexternal
has objective specification Agree a written statement of the decision problem that the evaluation and any model will address
has output type population specification, decision problem specification, intervention specification
has practitioner role health economics practitioner role
has subtask specification Define the evaluation perspective, Set the time horizon
inputs description The policy or clinical question, the technologies of interest and any scope issued by the decision maker.
normally precedes Develop an economic model

Define the evaluation perspective

https://healtheconomics.wiki/ontologies/heto/HETO_4000003

A task specification for stating whose costs and health outcomes an economic evaluation counts, such as those falling on the health system or on society as a whole, so that resources and outcomes are included consistently.

Type decision problem framing task specification
contributor Michelle Ashleyexternal
definition source Drummond et al. 2015
expected output description A perspective specification.
has action specification Identify the decision maker and any methods guidance that applies, Choose the perspective and list the kinds of resource it includes
has input type decision problem specification
has objective specification State the perspective of the evaluation and the kinds of cost and outcome it includes
has output type perspective specification
has practitioner role health economics practitioner role
inputs description The decision problem and any methods guidance from the decision maker.
involves type resource type specification
normally precedes Estimate resource use

Set the time horizon

https://healtheconomics.wiki/ontologies/heto/HETO_4000004

A task specification for choosing the period over which an economic evaluation counts costs and health outcomes, long enough to capture the differences between the options compared.

Type decision problem framing task specification
contributor Michelle Ashleyexternal
definition source Drummond et al. 2015
expected output description The time horizon, recorded in the decision problem specification.
has action specification Consider how long the effects of the options on costs and outcomes last
Record the chosen time horizon and the reason for it
has input type decision problem specification
has objective specification State a time horizon that captures all relevant differences in costs and outcomes between the options
has output type decision problem specification
has practitioner role health economics practitioner role
inputs description The decision problem and the evidence on how long the effects of the options last.
normally precedes Conceptualise the model structure
