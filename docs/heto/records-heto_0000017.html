Prepare the economic evidence for a health technology assessment submission

https://healtheconomics.wiki/ontologies/heto/HETO_4000017

A task specification for assembling the economic evidence for a technology, including the economic evaluation, its model and supporting documents, in the form set by the health technology assessment body that will appraise it.

Type reporting task specification
contributor Michelle Ashleyexternal
definition source HealthEconomics.wiki editorial (HETO 0.1.0)
editor note Definition is HealthEconomics.wiki editorial wording, for Darrin Baines to confirm. The evaluation it contains can also be part of other undertakings, such as an assessment group's own evaluation or a publication.
expected output description The economic sections of a submission dossier and the accompanying model.
has action specification Assemble the report, the executable model and the supporting documents in the format the body sets
Check that the assembled evidence is complete and consistent with the evaluation it reports
has input type economic model version, model result, documentexternal
has objective specification Provide the assessment body with economic evidence and a model it can review and rerun
has output type documentexternal
has practitioner role health economics practitioner role
has subtask specification Conduct a model-based economic evaluation
inputs description The economic evaluation, its model, and the methods guidance and templates of the assessment body.
involves type health technology assessment decision process, health technology assessment recommendation
term editor Michelle Ashley (drafted with Claude)

Report an economic evaluation

https://healtheconomics.wiki/ontologies/heto/HETO_4000016

A task specification for writing a full and transparent account of the methods, inputs, results and uncertainty of an economic evaluation, so that readers and decision makers can judge and reproduce it.

Type reporting task specification
contributor Michelle Ashleyexternal
definition source Husereau et al. 2022
expected output description A report of the economic evaluation.
has action specification Describe the decision problem, methods, inputs and assumptions, Present the results and the analyses of uncertainty, Check the report against a reporting checklist such as CHEERS 2022
has input type decision problem specification, economic model version, parameter assignment, model result
has objective specification Produce a report that sets out the methods and results of the evaluation completely enough for them to be assessed
has output type documentexternal
has practitioner role health economics practitioner role
inputs description The decision problem specification, the model version with its documentation and parameter assignments, and all results.
term editor Michelle Ashley (drafted with Claude)
