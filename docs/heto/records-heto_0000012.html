Estimate resource use

https://healtheconomics.wiki/ontologies/heto/HETO_4000007

A task specification for identifying and measuring the quantities of resources, such as staff time, medicines and hospital stays, used with each option or in each modelled health state, in natural units.

Type costing task specification
contributor Michelle Ashleyexternal
definition source Drummond et al. 2015
expected output description Resource use estimates in natural units.
has action specification Identify the kinds of resource that the perspective includes
Measure or estimate the quantity of each resource used from records, trials or published sources
has input type evidence source document, model state, evidence dataset, resource use record, perspective specification
has objective specification Obtain an estimate of the quantity of each relevant resource used, per person or per event, for each option or state
has output type resource use estimate
has practitioner role health economics practitioner role
inputs description The perspective, the model structure, and records or published sources of resource use.
involves type resource type specification
normally precedes Select unit costs
term editor Michelle Ashley (drafted with Claude)

Select unit costs

https://healtheconomics.wiki/ontologies/heto/HETO_4000008

A task specification for choosing the cost of one unit of each resource used in an economic evaluation, from sources that fit the perspective, the setting and the price year of the analysis.

Type costing task specification
contributor Michelle Ashleyexternal
definition source Drummond et al. 2015
expected output description Unit cost estimates with their source, currency and price year.
has action specification Find unit cost sources that match the perspective and setting
Choose a unit cost for each resource and adjust it to the price year of the analysis where needed
has input type evidence source document, perspective specification, tariff, currency conversion estimate, economic indicator record, resource type specification
has objective specification Attach a unit cost, with its source, currency and price year, to each kind of resource counted
has output type unit cost estimate
has practitioner role health economics practitioner role
has process type cost adjustment process
inputs description The list of resources counted, the perspective, and national or local cost sources.
normally precedes Value resource use
term editor Michelle Ashley (drafted with Claude)

Value resource use

https://healtheconomics.wiki/ontologies/heto/HETO_4000020

A task specification for multiplying the quantity of each resource used by its unit cost, and adding the results, to give the cost of each option or of each modelled health state from the stated perspective.

Type costing task specification
contributor Michelle Ashleyexternal
definition source Drummond et al. 2015
expected output description Cost estimates for each option or modelled health state, in a stated currency and price year.
has action specification Multiply each resource use estimate by the unit cost of that resource
Add the costs for each option or health state
has input type unit cost estimate, resource use estimate, perspective specification
has objective specification Obtain the cost of each option or modelled health state, in a stated currency and price year
has output type cost estimate
has practitioner role health economics practitioner role
has process type unit cost valuation process, cost aggregation process
inputs description Resource use estimates, unit cost estimates and the perspective.
normally precedes Calculate incremental cost-effectiveness results
