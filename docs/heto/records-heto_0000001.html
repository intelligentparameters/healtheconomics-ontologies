Conduct a model-based economic evaluation

https://healtheconomics.wiki/ontologies/heto/HETO_4000001

A task specification for comparing the costs and health outcomes of two or more options for a stated decision problem by means of an economic model, so that a decision maker can judge which option offers better value.

Type task specification
contributor Michelle Ashleyexternal
definition source Drummond et al. 2015
expected output description The results of the evaluation with their uncertainty, and a report of its methods and results.
has action specification Frame the decision problem the evaluation is to inform, Build or adapt an economic model and populate it with evidence, Estimate incremental results and describe their uncertainty, Report the methods and results of the evaluation
has input type evidence source document, decision problem specification, evidence dataset
has objective specification Estimate and compare the expected costs and health outcomes of the options in the decision problem, with the uncertainty around them
has output type model result, documentexternal
has practitioner role health economics practitioner role
has process type model run
has subtask specification Define the decision problem, Develop an economic model, Conduct sensitivity analysis, Validate an economic model, Calculate incremental cost-effectiveness results, Report an economic evaluation
inputs description The decision question, the options to be compared, and the clinical, cost and outcome evidence available.
involves type economic model
