Add discounting to an economic model

https://healtheconomics.wiki/ontologies/heto/HETO_4000010

A task specification for incorporating discounting into an economic model so that future costs and health outcomes are expressed in present-value terms using specified discount rates.

Type economic model development task specification
contributor Michelle Ashleyexternal
definition source Baines D. Defining tasks in HETO. Brief to the curator, 15 October 2026; Drummond et al. 2015
expected output description The model incorporating discounted costs and outcomes.
has action specification Apply the specified discount rates to relevant model calculations, Calculate discounted totals
has guidance resource NICE PMG36, NICE technology appraisal and highly specialised technologies guidance, the manual (published 31 January 2022, last updated 13 October 2026), section 4.5 Discounting. Methods guidance for England; link checked 16 October 2026external
has input type economic model version, cost record, QALY record, discounting specification
has objective specification Express future costs and outcomes in present-value terms
has output type economic model version, cost record, QALY record
has practitioner role economic modeller role
has process type QALY calculation process, cost adjustment process
inputs description Modelled costs and outcomes over time, specified rates and applicable guidance.
normally precedes Calculate incremental cost-effectiveness results
term editor Michelle Ashley (drafted with Claude)

Conceptualise the model structure

https://healtheconomics.wiki/ontologies/heto/HETO_4000006

A task specification for deciding how an economic model will represent the decision problem, including the modelling technique, the health states or events, the pathways between them and the main assumptions, before the model is built.

Type economic model development task specification
contributor Michelle Ashleyexternal
definition source Roberts et al. 2012
expected output description A documented model structure with its states, allowed transitions and structural assumptions.
has action specification Describe the disease process and care pathway relevant to the decision
Choose the modelling technique and the states or events to represent
Record the structural assumptions and the reasons for them
has input type evidence source document, decision problem specification
has objective specification Agree a model structure that represents the disease process and the decision problem well enough to inform the decision
has output type modelling assumption, model state, transition specification
has practitioner role economic modeller role
inputs description The decision problem specification, clinical evidence and expert advice on the disease and its care.
normally precedes Add discounting to an economic model, Estimate transition probabilities and treatment effects, Estimate resource use, Assign utility values to model health states
term editor Michelle Ashley (drafted with Claude)

Develop an economic model

https://healtheconomics.wiki/ontologies/heto/HETO_4000005

A task specification for building an economic model that represents a stated decision problem and combines evidence and assumptions to estimate the costs and health outcomes of the options compared.

Type economic model development task specification
contributor Michelle Ashleyexternal
definition source Briggs, Claxton and Sculpher 2006
expected output description An economic model version ready to be run.
has action specification Design the structure of the model, Populate the model parameters with estimates or stated assumptions, Implement the model calculations, including discounting
has input type utility estimate, cost estimate, unit cost estimate, resource use estimate, probability estimate, relative effect estimate, evidence source document, decision problem specification
has objective specification Produce an economic model version, with its structure and parameters, that can be run to estimate costs and outcomes for each option
has output type modelling assumption, economic model version, model parameter, parameter assignment
has practitioner role economic modeller role
has subtask specification Conceptualise the model structure, Add discounting to an economic model, Estimate transition probabilities and treatment effects, Estimate resource use, Select unit costs, Value resource use, Assign utility values to model health states
inputs description The decision problem specification and the estimates of clinical effects, resource use, unit costs, costs and utilities, with their sources.
involves type economic model
normally precedes Validate an economic model, Calculate incremental cost-effectiveness results
term editor Michelle Ashley (drafted with Claude)

Estimate transition probabilities and treatment effects

https://healtheconomics.wiki/ontologies/heto/HETO_4000018

A task specification for estimating, from clinical evidence, the probabilities of moving between the states of an economic model and the effects of each option on them, including any extrapolation beyond the observed follow-up, as inputs to the model.

Type economic model development task specification
contributor Michelle Ashleyexternal
definition source Briggs, Claxton and Sculpher 2006
expected output description Transition probability and treatment effect estimates assigned to the model parameters, with their uncertainty.
has action specification Find clinical evidence on baseline risks and on the relative effects of the options
Convert rates or survival data into transition probabilities for the model cycle
Extrapolate beyond the observed follow-up where the time horizon requires it
has input type evidence source document, evidence dataset, transition specification
has objective specification Give each transition and treatment effect parameter of the model a value, with its source and uncertainty
has output type probability estimate, event rate estimate, relative effect estimate, uncertainty specification, parameter assignment
has practitioner role economic modeller role
inputs description The model structure, trial reports, published studies and patient-level or survival data.
normally precedes Calculate incremental cost-effectiveness results
term editor Michelle Ashley (drafted with Claude)
